## 2. 工程边界

- 算法真源在本仓库 `src/chan/`，包测试在 `tests/`，实现与验收由本仓库交付;
  验收收据及其只读验证工具在本仓库 `validation/`、`validation/tools/` 维护;
  原图/真实标注的冻结输入与夹具在本仓库 `validation/`、`tests/fixtures/` 维护;
  108 课原文与需要外部获取的行情是显式输入前提;
- **不改已交付** `src/jq_*.py`、对应历史 `tools/build_*.py` 构建器和策略线
  (新能力的策略接入由后续验证流程独立决策);
- 不实现不可编码内容(心态/资金管理/杂史/政策守则);
- 当前 1.x 遵循 [API 稳定性规则](../API.md#1x-版本规则)，公开行为变化
  按主/次/修订版本登记并保留差异证据；已发布产物保持不可变。
  §5 的 0.x 阶段设计与旧验收数量作为历史保留，不作为当前兼容性规则;
- Python 3.6 / pandas 0.23 兼容目标; 新辅助模块优先仅用标准库 + typing。
  既有 MACD 计算依赖 numpy, DataFrame 适配使用 pandas, 包发布依赖仍为
  `numpy>=1.14` / `pandas>=0.23`;
- 文档/注释措辞纪律: 只记结论, 不写决策归因。

## 3. 每概念统一作业流程(SOP)

1. **读原文**: 精读维护者外层工作区 `doc/_extracted/课XXX.txt` 全文;
   关键定义存疑时对照 PDF 原页;
2. **定规格**: 提炼可编码定义——精确边界、输入输出、与已有模块关系;
3. **实现**: 新模块或已有模块新增函数, 注释规范见 §4;
4. **单测**: 每个定义分支至少一测; 优先构造能复刻原文判定边界的合成盘面;
   测试真源写在本仓库 `tests/`; `python tools/check_core.py` 自动发现全部包测试;
   外层项目只维护研究与平台集成测试，不桥接本仓库测试;
5. **登记**: 更新本文档 §6 进度表状态(已实现/部分/有意跳过+理由)。

## 4. 注释规范(执行全程强调)

- **模块级 docstring**: 理论依据(课号列表) + 原文关键定义直接引文(中文原文,
  标注课号) + 与理论的差异声明(如有);
- **函数级 docstring**: 功能、理论依据(课号)、每个参数/返回值含义与单位、
  边界行为(空输入/退化情形);
- **行内注释**: 每个判定分支(分类边界、阈值、方向切换)必须注释对应的原文
  依据或数学含义;
- **单测注释**: 每个测试 docstring 说明"覆盖原文定义的哪个分支/边界";
- 风格对齐现有 bi.py/xd.py/zs.py 并更详尽——可维护性核心靠注释回查原文。

## 7. 版本与发布纪律

- 当前为 1.x 维护阶段，按 [API.md](../API.md#1x-版本规则) 区分主、次、
  修订版本。概念独立提交，公开行为变化登记版本、输入边界和差异证据；
  工程治理和文档维护独立提交，不自动升级版本。
- 版本号在本仓库 `pyproject.toml` 与 `src/chan/__init__.py` 双处同步。
  提交信息用中文说明概念、课号或工程维护范围。
- 阶段发布前完成相应包测试、原文和指定真实数据验收，检查待发布文件。
  CI 集中构建一次候选 wheel/sdist，按提交、版本和摘要封存；现代与旧运行时
  验收同一候选，仓库资产独立验收，两个发布渠道复用已测产物。
- 包 Git 操作在本仓库根执行，外层文档与集成独立提交。外层子模块引用
  必须是已提交且可从远端获得的核心提交。
- 标签必须等于 `v<包版本>`，精确推送该标签；发布前后分别核验 main、tag、
  CI、Release 和 PyPI，不把本地完成当作远端发布。
- 已发布版本和标签保持不可变。历史小版本标签只按已核对的概念提交保留，
  不使用 `git push --tags` 顺带推送。阶段发布流程详见
  [CONTRIBUTING.md](../CONTRIBUTING.md)。

## 8. 风险与回滚

- **_extracted 提取错误**: 关键定义一律对照 PDF 原页复核;
- **理论多义性**: 取后期精确定义, docstring 标注口径;
- **级别递归(1d)操作性**: 理论只给存在性定义(课 63 自认"存在性 vs 操作性"),
  务实方案为"笔起逐级构造"; 若与原文走样, 降级为"笔/线段两级 + 扩展升级"并
  在进度表如实登记偏差, 不硬造;
- **兼容性**: 当前 1.x 遵循公开 API 契约，修正需登记行为差异并验证调用方。
  已发布版本保持不变，不自动升级冻结脚本依赖;
- **回滚**: 每概念独立 commit 可 revert; 影响面隔离在 src/chan 仓库内;
  已发版本不撤 tag, 用新版本修正。

**R3规格草稿（2026-10-13，课24/27/29/37/44/53/61/101全文核验后）**：

原文操作性条件（课号即依据）：

1. 背驰前提与比较段：趋势背驰以趋势为前提（走势至少含两个依次同向的
   同级别中枢，课27/37）；仅一个中枢时进入段与离开段的力度比较只能判
   盘整背驰（课27）；A、B级别不同时结构退化为围绕大中枢的震荡（课37）。
   盘整背驰是背驰力度比较法在中枢震荡上的推广用法，非独立理论等级
   （课53）；a+B+c中a、c对B的盘整背驰皆可视为中枢震荡比较（课53）。
   围绕同一中枢的两段走势即可比较力度（课61）；趋势背驰的标准比较为
   进入末中枢段与离开段。
2. 新极值与c段结构：顶背驰段未创新高（底背驰未创新低）则背驰不存在
   （课37/61），此时按围绕末中枢的次级别震荡处理（课37）。c为次级别
   走势且至少含末中枢的一个三类买卖点，b级别不大于c（最小连续缺口），
   c内部至少两个次级别中枢构成次级别趋势、可类区间套递归（课37）。
3. 力度判据与转折结构：力度比较为理论主判据；MACD（黄白线回抽0轴、
   柱面积前大后小、单柱急剧缩短）为辅助，其一即信号、双满足更标准
   （课24/27）。区间套：背驰段内部再找背驰段逐重嵌套，当下定位转折点
   （课27定理、课61四重背驰段图解）；未完成段先假设进入背驰段，实际
   力度大于比较段即背驰段不成立（课61）。背驰-转折定理（课29）：某级别
   趋势背驰导致该趋势末中枢的级别扩展、更大级别盘整或该级别以上反趋势。
   小背驰-大转折定理（课44）：小级别背驰引发大级别转折的必要条件是该
   级别最后一个次级别中枢出现三类买卖点，无充分条件。
4. 三类买卖点口径（课101精确表述、课53补充）：一类点=该级别背驰点，
   一、二、三类归根结底皆一类点、仅级别不同（课53）。二类买点=一类点
   后次级别离开走势结束、回头的次级别回试走势的结束点（课101；课53
   等价表述：高点一次级别向下后一次级别向上，不创新高或盘整背驰即
   二类卖点）；强弱三分：二三合一（最强，V型反转）、二类低于一类
   （最弱，对应盘整背驰及顺势到扩张平台）、一二三类依次抬高（一般）
   （课101）。三类点=中枢破坏点（课101），构成至少5段次级别（前三段
   成中枢、第四段离开、第五段构成三类点，课61）；二、三类重合时后续
   力度值得关注（课61）。一、二类买点只存在于回升中阴状态，中阴结束
   后仅剩三类点与中枢震荡买卖点（课101）；站在原下跌末中枢角度，一、
   二、三类买点皆可视为中枢震荡结果（课101）。

1. 中枢自身变化三态（课20回复："中枢延续与产生新中枢以及产生更

   围绕连续两个同级别中枢产生的波动区间产生重叠（课20级别延续
   定理二）。
2. 级别延续定理一（课20）：更大级别中枢产生前，该级别走势类型
   将延续（只具有该级别中枢的盘整或趋势的延续）。
3. 递归级别与结合律（课35/70）：级别由递归层级严格定义（三个
   连续最低级别走势类型重叠构成高一级中枢，逐级上推），1/5/30
   分钟等K线周期只是不大严格的方便说法；走势连接符合结合律、
   不符合交换律，理论是走势保持结合律下具有变换不变性的一套
   理论（课70）；任何级别走势类型都至少由三段以上次级别走势
   类型构成（课35分解定理二）。
4. 九段延伸与级别分辨（课69）："九段可延伸成5分钟中枢，可不等
   于5分钟中枢就一定是九段"；线段延伸九段后形成的高级别中枢
   同样可看成三个次级别走势类型的重合；中枢级别由组成次级别
   走势类型的递归层级分辨（课69日线背驰段答疑："前后两个中枢
   是同级别的……仔细的划分，可以从1分钟图上的中枢级别来分辨"），
   不是段数、振幅或K线周期。
5. 中枢形成后理论上只有三种走势（课70）：向上第三类买点走出
   次级别走势类型后构成新的同级别中枢；向下第三类卖点同构；
   中枢延伸，或出现第三类买卖点后扩展成大级别中枢。多样性
   分解原则（课70）："新的5分钟中枢，暂时先从最后一个1分钟
   中枢开始算起……等走势走出最自然的选择再继续更合理的划分"。
6. 轮次与中阴（课101/108）：一类买点出现后至该买点所引发中枢
   第一次走出第三类买卖点前都是底部构造过程（课108精确底部
   定义）；三类卖点先出现=底部构造失败，三类买点=底部构造最终

   中阴结束后只剩三类点与中枢震荡买卖点（课101）；二类买点=
   一类点后次级别离开走势结束、回头的次级别回试走势结束点
   （课101）；一、二、三类买点归根结底皆一类点仅级别不同（课53）。
7. 买卖点级别定理（课35）：大级别买卖点必然是次级别以下某一级
   别买卖点（不一定是次级别）；第三类买卖点必须是第一次回试
   （课20/69），第三类买卖点后不必然是趋势，也有进入更大级别

### 11.11 正式1.0.0的必过门槛
