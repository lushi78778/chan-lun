# R2 一类买卖点（0.9.9）真实正反例独立标注

核验时间：2026-10-13（北京时间）。0.9.2—0.9.6 严格趋势（a/A/b/B/c/
proof 角色、Zn 冻结、gap、逐前缀台账）与 0.9.3 完成口径继续有效，

## 裁定（0.9.9 新增）

1. **成立三条件**：先为完成严格趋势（0.9.3 口径：B 按离开冻结、
   c 离开最后中枢核心、证明段紧随 c 自外侧回核心、gap>0）；背驰
   0<area_c<area_b（课24 行31-33 面积判据）；c 创全趋势新极值
   （先验极值取 a 或 A 首 Zn 成员..B.zn[-1] 单元范围，含 b 与
   中间反向单元）。三条件同时成立才裁定一类买卖点成立。
2. **不成立二分**：无背驰 no_divergence（面积判据不满足，不判
   极值）；无新极值 no_new_extreme（面积减弱成立但 c 未超越全
   趋势先验极值）。
3. **MACD 口径**：EMA(12,26,9) 固定自窗口首行起算（首值种子、
   k=2/(n+1)），hist=(DIF-DEA)*2；面积=b/c 单元同方向柱正幅值
   和，区间(start,end]（柱归属按原始行，共用端点不重复计数）；
   area_b 取 b=A.zn[-1]+1、area_c 取 c=B.zn[-1]+1。EMA 起点是
   测试约定，不证明窗口前历史对指标无影响。
4. **零轴回拉**：max(|DIF|,|DEA|)/close 于 B zn 区间最小值，仅
   记录性登记，不作裁定门槛（课24 明示 MACD"不绝对精确"；工程
   零轴门槛不能当严格证明，同 §11.6 R3 保留身份与局限）。
5. **可见时刻**：裁定事件可见=证明段（proof）单元首确认，
   first_raw_count 按逐原始 bar 前缀首次可见冻结；分型/笔端点
   时间不等于确认时间，禁止确认时间回填。
6. **扫描与发现**：strict_scan_v3（0.9.3 冻结口径）四窗复现
   通过后全量扫描 1d/60m/30m 与 5m 2026 分区：1992 completed/
   802 hits/52 唯一成立趋势；扫描结果仅作发现，入选窗一律以窗内
   重跑冻结验证（逐前缀证明段确认在窗口内，无前视）。
