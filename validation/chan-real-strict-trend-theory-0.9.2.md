## 裁定

1. **完成严格趋势口径（课29，R1读法）**：c 必须离开最后中枢的核心区间
   （up: c 内 up 段 high>B.ZG；down 镜像），课29原文"最后的背驰段，
   跌破该中枢后"（`课029.txt:20`）；证明段必须自外侧回到最后中枢核心
   （课29"反弹至少要重新触及最后一个中枢"`课029.txt:42`）。两条件同时
   成立才计完成；核心离开已是最宽读法，更严读法（如要求 c.low<B.DD）
   只会减少计数。
2. **B+c 中枢扩展不算完成**：课29"如果 B+c 发生中枢扩展……把 a+A+b
   用 a~ 表示，而 B+c 发生中枢扩展用 A~ 表示"（`课029.txt:71-74`），
   这是"一个未完成的走势类型的延续"，仍在一个走势类型里；扩展成高级别
   中枢后按课20定理二合并分支另行登记，不回填为完成严格趋势。
3. **Zn 约定仅用于核心计算**：课20"回升形成的中枢，由向上的次级别走势
   类型的区间重叠确定"（`课020.txt:56-58`），Zn 取与中枢形成方向一致的
   次级单元；`ZD=max(d1,d2), ZG=min(g1,g2)` 由首对同向段固定
   （`课020.txt:60-61`）。中枢存在性与 Zn 方向约定无关：任意方向三连续
   次级走势重叠即中枢（`课017.txt:35-36`）。共享端点交替单元下只查
   (s, s+2) 同向对是完备的——中间单元必覆盖 [ZD,ZG]。
4. **延伸=闭区间触沿**：课20定理一"走势中枢的延伸等价于任意区间
   [dn,gn] 与 [ZD,ZG] 有重叠"（`课020.txt:68-70`），工程取 `<=/>=`
   触沿口径；首个未触沿的同向单元封口（closed_by），封口单元区间
   不再改写已定 ZD/ZG。
5. **定理二合并四分支穷尽**：`课020.txt:72-74`——后 GG<前 DD 等价下跌
   及延续；后 DD>前 GG 等价上涨及延续；后 ZG<前 ZD 且后 GG>=前 DD，
   或后 ZD>前 ZG 且后 DD<=前 GG，等价于形成高级别走势中枢。核心重叠的
   两中枢实为同一延伸中枢（定理一），不进入合并分支。
6. **a 与 c 并非必然存在**：课33"在 a+A+b+B+c 的走势系列类型里，
   a 和 c 并不是必然存在的"（`课033.txt:46`）。R1 读法要求完整
   a+A+b+B+c 角色与转折证明；R2 读法允许 c 缺席，为待判边界，
   本轮不强行裁一。R2 下完成计数不增：c 离开+证明仍为必要条件。
   R1/R2 两种读法并列登记于发现输出 readings 字段。
7. **窗口规则**：自然起点、不移动起点、无窗口前暖机、因子恒1区间；
   独立标注不导入 chan，整数 tick（0.001）算术独立冻结后再与库比较。
   行情末端锚定观察日；分型/笔端点时间不等于确认时间，台账按逐原始日
   前缀重放取首次可见，禁止确认时间回填。
8. **台账语义**：全部用固定单元（bis[:-1] / complete XD）。固定单元
   区间必为最终（后继单元形成即定）；A/B/C 的 Zn 成员只增不减、
   ZD/ZG 由首对同向段固定、DD/GG 单调展宽、closed/merged/departed
   一旦确定不变。台账事件按首次可见的原始行数冻结 first_raw_count，
   到达时刻按日线 15:05 测试约定。
